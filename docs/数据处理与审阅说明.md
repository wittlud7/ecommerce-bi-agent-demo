# 数据处理与审阅说明

本展示版采用全量独立模拟的方式处理数据。原始数据不是改名、打码、按比例缩放或抽样后留存，而是完全不进入发布目录；没有真实人员与演示人员之间的映射表。

## 进入展示版的内容

- 看板 HTML、CSS、图表与筛选交互。
- 通用 SQL 汇总、趋势、对比及下钻分析代码。
- 重新生成的模拟数据库、虚构业务对象和独立数字。
- 重新设定并明确标注的演示趋势判断阈值，不沿用原业务阈值。
- 重新整理的本地启动服务与 Agent 工作流。
- 第三方图表库、Markdown 渲染库及通用行政区划底图。

## 未进入展示版的内容

- 原始订单、客户资料、人员账号、商品映射及 Excel 导出。
- 生产 SQLite 文件及其元数据、残留页或写前日志。
- 原登录用户、密码哈希、权限配置和企业密钥。
- 原 `.env`、`.mcp.json`、工作站路径、内网地址、生产服务连接配置。
- 旧 `.git` 历史、工具缓存、字节码、日志、审计备份、截图及压缩包。
- 企业 Logo、生产说明文档、内部经营方案和历史 Agent 对话。

## 可由本人检查的项目

1. 页面顶部始终说明是模拟数据；店铺、人员、账号和产品名称有“演示”或“示例”标识。
2. 运行生成器后，`provenance.json` 声明读取原业务文件数为 0；代码中没有打开原文件的路径。
3. 数据库由新的 SQLite 文件创建，所有业务行只来自生成器。
4. Python 看板与 Agent 读取同一模拟库，静态看板与 Agent 读取该库导出的同一模拟 JSON；默认不调用外部模型或生产系统。
5. Agent 展示范围、工具调用和结果分层，数值不是预置的一段固定回答。
6. 本目录没有 `.git`；将来应在本目录新建仓库，避免引入旧历史。

原始项目和压缩包仍作为本地文件保留在上级目录，它们不是本次可发布成果。阅读本说明不需要把任何原文件上传至第三方。

本次检查的范围是公司数据与访问材料是否进入公开演示版，以及核心展示功能是否可用；外部 LLM 和 MCP 客户端连接需分别配置和验证。
